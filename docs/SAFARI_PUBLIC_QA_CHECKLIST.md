# 公開前・Safari実機確認票

この確認票は、ローカル表示とiPhoneのSafari／ホーム画面アプリの表示差を、公開前に確認するためのものです。個人データは記録せず、版・画面・結果だけを残します。

## 1. 公開前の版確認

- [ ] `version.txt`、`index.html` の `BUILD`、JS/CSSのクエリ版、`sw.js` のキャッシュ版が一致している
- [ ] `tools/check.ps1` の静的契約検査が完了している
- [ ] ローカル確認URLに新しい版を付け、旧タブを再利用せず開いている

## 2. ローカル実表示

- [ ] PC幅でホーム、仕事、生活、時間割、体調、設定を開く
- [ ] 幅390px前後で同じ画面を開き、横スクロール・枠からのはみ出しがない
- [ ] 日付、時刻、時間軸、中央線、選択中の予定の直下の操作が揃っている
- [ ] 予定のタップ、長押し移動、開始／終了調整、ページスクロールを確認する
- [ ] 読み取り専用端末では保存操作が無効である
- [ ] 日報取り込みは「ファイル選択 → プレビュー → 明示保存」の順で、既存日報を上書きしない
- [ ] DevToolsのエラーがない

## 3. 公開後のSafari実機

- [ ] 公開URLをSafariで新規タブから開く
- [ ] 画面内の版表示が確認した版と一致する
- [ ] 横スクロールがなく、基本文字・数字・日付・時刻が意図した位置にある
- [ ] 時間割の仕事／生活カードと中央線が、表示幅を変えても構造上の中央にある
- [ ] iPhone側の書き込みだけが保存でき、PC側の読み取り専用を維持する
- [ ] Safariの再読み込み後も同じ版が表示される
- [ ] ホーム画面アプリとして開き直し、旧CSS／旧JSが残っていない

## 4. 合格条件

公開を合格とするのは、PC・390pxローカル・Safari実機・ホーム画面アプリの4箇所で、版一致、横はみ出しなし、日付／時間ずれなし、主要操作の意図しない保存・詳細表示なしを確認できた場合です。いずれか未確認なら「公開済み」ではなく「確認待ち」と扱います。

## 5. 記録形式

確認日／版／URL種別（local・public・PWA）／端末幅／画面名／結果／再現手順／スクリーンショットの順で記録します。個人情報、日報本文、金額、健康値は記録票に転記しません。
