くらしのしるし：歩数・睡眠の自動取り込み

この設定は「端末データ同期」とは別です。

・端末データ同期
  PC と iPhone のアプリ記録（お金、予定、メモ等）を同期します。
・ヘルスケア自動取り込み
  iPhone ショートカットから、歩数・睡眠だけを専用の受信箱へ送ります。

同じ Gist ID を両方に使わないでください。

1. アプリで専用の受信先を作る

  1) 設定 →「ヘルスケア自動取り込み」を開く
  2) GitHub の classic Personal Access Token（gist 権限）を入力
  3) Gist ID は空欄のまま「受信先を新規作成」を押す
  4) 表示された「ショートカットの送信先 URL」を控える

2. iPhone のショートカットを直す

  「URLの内容を取得」アクションを開き、次の内容にします。

  URL
  https://api.github.com/gists/＜アプリが表示したヘルスケア受信用Gist ID＞

  方法
  PATCH

  ヘッダ（1行ずつ、キーと値を分けて入力）
  Authorization : Bearer ＜GitHubトークン＞
  Content-Type  : application/json

  本文を要求：JSON
  {
    "files": {
      "inbox.txt": {
        "content": "kenko|YYYY-MM-DD|歩数|就寝時刻|起床時刻"
      }
    }
  }

  例
  {"files":{"inbox.txt":{"content":"kenko|2026-08-09|1234|23:40|07:10"}}}

  注意：URLの中にトークンを入れません。トークンは Authorization ヘッダの値だけに入れます。

3. 動作確認

  1) ショートカット編集画面下部の再生（▶）を押す
  2) アプリの 設定 →「ヘルスケア自動取り込み」→「受信を確認」を押す
  3) からだとこころ画面で歩数・睡眠が更新されたことを確認する

エラーの意味

・404 Not Found
  URLのGist IDが違う、またはトークンがそのGistにアクセスできません。
・401 / 403
  トークンの貼り間違い、期限切れ、または gist 権限不足です。
・ショートカットの通信エラー
  通信状態を確認してから、URL、PATCH、ヘッダ、本体JSONを見直します。

この受信箱に届いたデータは、アプリが取り込んだ後に空にします。アプリの家計簿・予定・メモのデータは変更しません。
