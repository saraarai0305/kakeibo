# ヘルスケア自動取り込み

歩数・睡眠の受信は、端末データ同期とは別の **専用Gist受信先** を使います。

## 現行手順

1. アプリの「設定」→「ヘルスケア自動取り込み」を開く。
2. Gist権限だけを持つGitHubトークンを入力する。
3. 受信先Gistを新規作成する。端末データ同期と同じGist IDを使わない。
4. iPhoneショートカットから、次の1行を `inbox.txt` にPATCHで送る。

```text
kenko|YYYY-MM-DD|歩数|就寝時刻|起床時刻
```

例: `kenko|2026-08-10|8250|23:40|07:30`

- 歩数だけ: `kenko|2026-08-10|8250||`
- 睡眠だけ: `kenko|2026-08-10|||23:40|07:30`

詳細なiPhone操作は、同じフォルダの手順書を参照してください。トークンは画面・共有・設計書に残さないでください。

## 手順書

- `iPhone_歩数と睡眠_専用受信先への移行手順.txt` — 現行方式（専用受信先）の設定
- `iPhone_歩数と睡眠の自動取り込み手順.txt` — ショートカット作成の詳細と旧方式の補足
