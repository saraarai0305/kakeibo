【旧方式・参考資料】くらしのしるし｜iPhoneで歩数・睡眠を自動取り込みする手順

この文書は旧方式の履歴です。新規設定・再設定は、同じフォルダの
`README.md` と `iPhone_歩数と睡眠_専用受信先への移行手順.txt` を使ってください。
現行方式では、端末データ同期とヘルスケア自動取り込みを別のGistに分けます。

【はじめに】
このアプリはPWAのため、iPhoneのヘルスケアを直接・常時読み取ることはできません。
iPhoneの「ショートカット」がヘルスケアの値を非公開Gistの受信箱へ送信し、
アプリを開いた時と、開いている間（45秒ごと）にアプリが取り込みます。

----------------------------------------
1. アプリ側の同期を準備する（最初の一度だけ）
----------------------------------------
1) くらしのしるしを開く
2) 右上の「設定」→「同期・歩数／睡眠」を開く
3) GitHubトークンとGist IDを入力し、「同期を設定・開始」を押す
4) 表示が「同期済み」になったら準備完了

※ GitHubトークンは「gist」権限だけのものを使ってください。
※ このトークンはショートカットにも入力します。人に見せたり共有したりしないでください。

----------------------------------------
設定後、いま表示されている画面で行うこと
----------------------------------------
画面上部の「毎日、21:30に」は、実行時刻の設定が終わっている状態です。
次は「その時刻に何を実行するか」を作ります。

1) 左上の灰色の「新規ショートカットを作成」をタップ
2) 開いた編集画面で「アクションを追加」をタップ
3) 下記の「アクションの流れ」のブロックを、上から順番に追加

※ 赤い「歩数コピー」は以前のクリップボード用ショートカットです。
  今回の自動取り込みには使いません。
※ 最初からヘルスケアを組む前に、下の「送信テスト」を一度行うと、
  Gist ID・トークン・アプリ側の受信が正しいかを安全に確認できます。

【送信テスト（最初の一度だけ）】
アクションを追加 →「テキスト」を検索して追加し、次を入力します。

kenko|2026-08-09|1234||

続けて「Gistへ送る共通手順」の「URLの内容を取得」を追加して実行します。
くらしのしるしを開き、「今すぐ同期する」を押して 1,234歩が入れば接続成功です。
成功後、この固定テキストを下記の歩数用アクションへ置き換えます。

----------------------------------------
2. 歩数を毎晩自動送信するショートカット
----------------------------------------
ショートカット App → オートメーション → ＋ →「時刻」

設定：
- 時刻：21:30（好きな時刻で可）
- 繰り返し：毎日
- 実行：すぐに実行
- 実行前に尋ねる：オフ

アクションの流れ：
1) 「ヘルスケアサンプルを検索」を追加
   種類：歩数
   期間：今日
2) 「ヘルスケアサンプルの詳細を取得」を追加
   詳細：値
3) 「統計を計算」を追加
   演算：合計
4) 「現在の日付」を追加して「日付をフォーマット」を追加
   形式：yyyy-MM-dd
5) 「テキスト」を追加して、次の形にします。
   kenko|日付|歩数||
   例：kenko|2026-08-09|8234||
   「日付」と「歩数」には、上のアクションの青い変数を挿入します。
6) 下の「Gistへ送る共通手順」で送信する

----------------------------------------
3. 睡眠を毎朝自動送信するショートカット
----------------------------------------
ショートカット App → オートメーション → ＋ →「時刻」

設定：
- 時刻：09:00（起床後の好きな時刻で可）
- 繰り返し：毎日
- 実行：すぐに実行
- 実行前に尋ねる：オフ

アクションの流れ：
1) 「ヘルスケアサンプルを検索」
   種類：睡眠
   期間：前日から今日
2) 睡眠中の最初の開始時刻を「就寝」、最後の終了時刻を「起床」にする
3) それぞれを HH:mm 形式にフォーマットする
4) 「現在の日付」を yyyy-MM-dd 形式にフォーマットする
5) 「テキスト」に次を作る
   kenko|日付||就寝|起床
   例：kenko|2026-08-09||23:40|07:30
6) 下の「Gistへ送る共通手順」で送信する

----------------------------------------
4. Gistへ送る共通手順
----------------------------------------
ショートカットの最後に「URLの内容を取得」を追加します。

URL：
https://api.github.com/gists/ここにGist ID

方法：PATCH

ヘッダ：
- Authorization : Bearer ここにGitHubトークン
- Content-Type : application/json

リクエスト本文（JSON）：
{
  "files": {
    "inbox.txt": {
      "content": "上で作ったテキスト"
    }
  }
}

送信後は、くらしのしるしを開いてください。
アプリは受信箱を確認し、歩数・睡眠を自動で反映します。

【確認方法】
- 設定 →「同期・歩数／睡眠」→「今すぐ同期する」
- または、アプリを開き直して45秒ほど待つ

【大切な注意】
- iPhoneのPWAが完全に閉じている間、アプリ自身は読み込みを実行できません。
  ただしショートカットはGistへ送れるため、次にアプリを開いた時に取り込まれます。
- 歩数用と睡眠用を別々に送る場合は、アプリを一度開いて取り込んでから次を送るか、
  1つのショートカットで歩数・就寝・起床をまとめて送ると確実です。
- 途中で困った場合は、アプリの「設定」→「同期・歩数／睡眠」で接続状態を確認してください。
