## 使い分け

- `archive/` は置き換え済みの提案・実装記録。削除せず、判断の経緯を残す。
- PNG / PDF / DOCX はデザイン成果物。生成元のスクリプトが `tools/` にあるため、名前・場所を変えない。
- 確認は常にローカルの**実表示ページ**で行う。コード表示・圧縮スクリーンショットだけで承認しない。
- 公開前には `tools/check.ps1` と、実データを流した画面遷移確認を通す。

## 更新手順

1. 変更対象に対応する正本を読む。
2. 目的、変更点、再発防止を正本または実装記録に残す。
3. 実表示で確認する。
4. 動作確認後に公開する。
