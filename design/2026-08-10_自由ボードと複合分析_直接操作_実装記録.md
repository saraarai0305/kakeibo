# 自由ボードと複合分析：直接操作の実装記録

> 開発中の確認でも、実際に読み込む CSS / JavaScript のクエリ版を同時に更新する。ソースだけ直してブラウザが旧キャッシュを表示する状態を、確認済みとして扱わない。

更新日: 2026-08-10

## この変更の目的

「生活の基盤をこれ一つで支える」というアプリの目的に沿って、考えを並べる画面と、体調を比較する画面の操作量を減らす。画面内の情報を読むだけでなく、必要な箇所だけを直接触って確認・整理できる構造にする。

## 自由ボードの操作契約

- ボードの表示枠は固定し、空白部分のドラッグで**ボード内容だけ**を移動する。ページ全体は移動しない。
- 二本指のピンチで `65%〜260%` の範囲を拡大・縮小する。
- テキスト、図形、メモ、手書き、画像をツールで追加する。
- テキスト・メモは内容量から高さを自動算出し、文字がボックス外で切れないようにする。
- 長押しで移動する。図形・メモ・画像だけは四隅のハンドルで大きさを変えられる。テキスト入り要素は手動リサイズをさせない。
- 一回タップは要素全体の選択、テキスト／メモの二回タップ（PC はダブルクリック）は**ボード上の文字を直接編集**する。編集欄をクリックして開く必要はない。Safari のため、選択中の同一要素を 820ms 以内にもう一度タップしても直接編集へ入る。
- 「テキスト」「メモ」ツールで新規配置した場合は、配置直後から本文を入力する。選択だけで入力できない状態を残さない。
- 選択中は流れる破線と右上の削除ボタンを出す。横揺れは使わない。
- 選択外の空白をタップすると選択解除する。
- 書体・太さ・文字サイズはポップアップで指定する。文字サイズは数値入力を用いる。

## 体調分析グラフの操作契約

- 一週間の比較は一つのグラフで行う。
- 睡眠・歩数は同じ曜日の X 座標上に重ねた棒グラフ、からだ・こころ・毎日の習慣は形状を変えた折れ線で示す。
- 値の説明はグラフ内に重複表示しない。点・棒・線を選ぶと、対応色で `こころ 3/5` のように一項目だけ表示する。
- 同じ位置で睡眠と歩数が重なる場合、連続タップで睡眠→歩数を切り替える。
- 折れ線は点だけでなく線の途中も選択可能にする。
- 詳細表示にアニメーションは付けない。比較を繰り返す操作を妨げないためである。
- 二本指で `85%〜260%` の範囲を拡大・縮小する。
- 振り返りには平均睡眠、平均歩数、推定消費カロリー、毎日の習慣を表示する。

## 分析するボタンの安全な範囲

- 現段階では、端末内の記録値のみから平均値と相関係数を用いる補助的な傾向を表示する。
- これは診断ではない。睡眠・こころ・からだの医療判断を行わない。
- 将来 AI 分析を追加するときは、PWA 内に API キーを置かない。利用者が明示的に同意したデータだけを、認証付きサーバー経由で送る。
- 研究根拠を表示する場合は、一次論文または公的機関の情報に出典を結び付ける。

## 再発防止・実装規則

- 新しい操作は `data-v2-freeboard-*` / `data-v2-health-*` のように名前空間を分け、旧 UI のイベントと混ぜない。
- `pointerdown` 時に不要な再描画を行わない。ドラッグ対象を消してしまい、長押し・移動を阻害するため。
- 選択・移動・拡大縮小を変更した後は、必ず実表示のローカルページで確認する。コード表示や低解像度のスクリーンショットのみで完了判定をしない。
- 選択状態は静止した装飾と混同しないよう、流れる破線など状態変化が分かる表現を使う。
- 成功通知は設定で無効化できるようにし、入力不足などの注意は常に残す。

## 2026-08-10 追加：自由ボードの見た目と操作の確定規則

### 選択枠

- テキスト／メモ自身の紙の枠は **1 本だけ** にする。選択時に外へ現れる枠は内容の枠ではなく、選択中であることを示す状態表示である。
- 状態表示は、要素より 7px 外側の **角丸 SVG の流れる点線** に統一する。CSS の直線的な背景パターンで擬似的に枠を作らない。これにより、角で四角く見える再発を防ぐ。
- 選択解除時には外側の点線・削除ボタン・書式ボタンをすべて消し、通常の枠だけを残す。

### 操作の流れ

1. **選択**：選択ツールで要素を 1 回タップ／クリックする。角丸点線、右上の削除、テキスト／メモでは `Aa`（書式）が現れる。
2. **テキスト／メモ**：選択済み・未選択を問わず、文字を 2 回タップ／ダブルクリックすると、その場の文字が編集欄に切り替わる。入力中に内容に合わせて枠の大きさを自動調整する。空白部分をタップするか、フォーカスを外すと保存する。
3. **図形／画像**：1 回タップで選択。長押し／ドラッグで移動し、表示された周囲のハンドルで大きさを変更する。
4. **手書き**：手書きツールを選び、ボード上をドラッグして描く。線も選択・移動・削除できる。
5. **空白**：ドラッグでボードの表示位置を動かす。二本指ではボードだけを拡大縮小する。ページ自体を動かさない。

### 文字・アイコン・バージョン表記

- 自由ボードのツール名はすべて `--board-font-sans`、11px、800 weight を使用する。ツールのアイコンは個別 SVG を必ず表示し、選択はカーソル、テキストは鉛筆、図形は角丸四角、メモは紙、手書きはペン、画像は写真で区別する。
- `VER.` と値は、ホームと各ページで同じ `--v2-version-size`（11px）、同じ書体・太さ・字間・数字設定を用いる。画面ごとの個別指定を作らない。

### 確認手順（必須）

- 変更後は、静的 HTML やコード表示ではなく、`127.0.0.1:8766` の実アプリで確認する。
- テキストの選択、PC のダブルクリック、点線角丸、アイコン表示、ホームと内ページの `VER.` の computed style を実機表示で確認してから完了とする。

# 2026-08-10 verification and prevention log

## Product requirement

- The board viewport is fixed. A drag on empty space pans only board content; it must never scroll the document.
- Two active pointers scale the board or chart about their midpoint. Ending either pointer clears the pinch state, preventing a stale gesture from affecting the next drag.
- Text and memo objects use auto-fit dimensions derived from their displayed content. They deliberately have no resize handles. Shapes and images have eight resize handles: four edges and four corners.
- A single tap selects an object; a double tap opens the text editor. Tapping outside objects deselects it. The selected border uses a flowing dashed pattern only; no wobble animation is permitted.
- Small icon controls, including delete and resize controls, use explicit `display:grid; place-items:center` alignment. Never rely on font baselines or glyph whitespace to centre symbols.

## Health chart requirement

- One combined graph shows sleep and steps as bars at the same weekday x position. Body, mind, and daily habits are distinguished as lines by colour, point shape, and line pattern.
- A tap displays one coloured metric label only. When bars overlap, repeated taps cycle their values. Line paths as well as points are hit targets.
- The review area shows weekly average sleep, average steps, estimated calories, habits, and a deterministic local relationship summary. Any future ChatGPT analysis must call a server-side endpoint; no provider key may be embedded in the PWA.

## Review protocol

1. Validate JavaScript syntax before opening the review page.
2. Open the actual local app in the in-app browser and test UI there. Do not treat raw source code or a static screenshot as visual approval.
3. Record testable evidence separately from assumptions. Empty health data may verify chart structure but cannot verify a non-zero metric detail until a real record exists.

## 2026-08-10 — フリーボードの拡縮・削除操作規則

- **辺のハンドル**：動かした辺だけを移動し、反対側の辺は常に固定する。最小サイズまたはボード端に達しても、反対側が押し広げられる挙動は禁止。
- **角の丸ハンドル**：横・縦を同時に変形できる。各方向とも、反対側の辺を固定して拡縮する。
- **PC の拡大縮小**：ポインタがフリーボード表示枠の内側にある時だけ、マウスホイールで拡大縮小する。ページ全体のスクロール操作には干渉しない。
- **削除**：iPhone はオブジェクトを動かさずに長押しした場合のみ右上に × を表示する。PC は右クリックで小さな「削除」メニューを表示する。削除操作と拡縮ハンドルは重ねない。
- **確認手順**：実装後は必ずローカル実表示をブラウザで開いて確認する。コードのみをユーザーへ表示しない。

## 2026-08-10 — 同列ツールと選択枠の再発防止

- 同じ高さ・同じ操作グループに並ぶアイコンと文字は、意味・形状・外接範囲が重ならないことを実装前に確認する。利用者が位置を微調整する前提にしない。
- フリーボードの文字ツールは、手書き（ペン）と区別するため **「あ」** を使用する。追加アイコンは必ずアイコン一覧にも追記する。
- 図形を選択したときは、テキストと同じ角丸の流れる点線を図形の外周に表示する。変形用の丸ハンドルは選択枠より内側に置き、図形外周との位置関係を固定する。
- ブランド表記は「くらしのしるし」にそろえ、設定画面の見出しも **「くらしの設定」** とする。
