# 2026-08-09 アイコン一覧・追加分

すべて 24px 方眼、2D 線画、同じ線幅を使う。座布団へ入れる場合も、SVG 自体を拡大縮小して中心を合わせるのではなく、固定サイズのコンテナを `grid` 中央揃えにする。

| 用途 | アイコン | 意味 |
|---|---|---|
| 仕事 | ブリーフケース | 仕事・制作・納品・集中作業 |
| 生活 | 家 | 生活・家事・休息・私用 |
| 記録 | 鉛筆 | 記録する入口・アイデア |
| お金 | 円入りコイン | 支出・収入・お金の分析 |
| 体調 | ハート / からだ | こころとからだの記録・分析 |
| こよみ | カレンダー | 予定・週／月表示 |
| 見える化 | 棒グラフ | 分析・比較 |
| 戻る | 左矢印 | 一つ前の画面へ戻る |
| 設定 | 横線三本 | 設定メニュー |

## 変更履歴

- 仕事と生活のアイコンを追加。時間割・週月フィルターでは文字だけに依存せず、アイコンと名称を対で表示する。
- 既存のアイコンは、立体表現・絵文字・フォント記号を混ぜず、この 2D 線画ルールへそろえる。
