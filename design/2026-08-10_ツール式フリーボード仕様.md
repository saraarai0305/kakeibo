# ツール式フリーボード仕様

更新日: 2026-08-10
対象: `アイデアと目標` ページ

## 目的

アイデアと目標は、箇条書きや固定レイアウトのカードではなく、自由に配置・組み立てられる一枚の作業面とする。Illustrator / Photoshop / Freeform のように、まずツールを選び、キャンバスへ直接置く操作を基本にする。

このページの役割は「生活を支える記録」とは別に、プラグイン・映像・生活設計の発想を視覚的に育てること。

## 画面構成

1. ページ上部に `アイデアと目標` を表示する。
2. 直下に横並びのツールパレットを置く。
3. 下には内容の縮小プレビューだけを表示する。
4. プレビューをタップすると全画面キャンバスを開く。
5. 全画面では、ページ内のカードや説明を出さず、ツール・キャンバス・最小限の文字設定だけを表示する。

## ツール

| ツール | 操作 | 保存される要素 |
| --- | --- | --- |
| 選択 | タップで選択、ドラッグで移動 | 既存要素 |
| テキスト | キャンバスをタップして文章を置く | テキスト |
| 図形 | キャンバスをタップして角丸の図形を置く | 図形 |
| メモ | キャンバスをタップして付箋を置く | メモ |
| 手書き | ドラッグして線を描く | ストローク |
| 画像 | 端末から選んだ画像を置く | 画像 |

テキスト・メモは、選択したときだけ書体、太さ、文字サイズを編集できる。画像・図形・手書きは、選択・移動・削除を可能にする。

## データ移行

- 既存の `monthlyGoal`、`ideas`、`images` は消さない。
- 既存メモはテキスト要素、既存目標は目標メモ、既存画像は画像要素に変換して表示する。
- 保存先は既存の `ideaBoard.cards` を継続し、端末内の既存記録を保持する。
- 画像は長辺 1280px に圧縮して、端末データの肥大化を抑える。

## 文字とフォント

### 「等幅」とは

すべての文字が同じ横幅を使う書体（タイプライターやコード表示向け）のこと。日本語の通常の文章やアプリ画面の既定書体には使わず、必要なときだけ選択肢として使う。

### 実在フォントの扱い

Windows 側で確認できる書体を優先順に CSS のフォントスタックへ入れる。

- ゴシック: `Noto Sans JP` → `BIZ UDPGothic` → `Yu Gothic UI` → iPhone の `Hiragino Sans`
- 明朝: `Noto Serif JP` → `BIZ UDPMincho` → `Yu Mincho` → iPhone の `Hiragino Mincho ProN`

PCにしかないフォントファイルは、iPhone から直接利用できない。フォントをアプリに同梱する場合は、ライセンスを確認したうえで別途導入する。現段階では、各端末の適切な代替書体へ自然に切り替わる設計にする。

## 共通デザイン規則

- 枠内のアイコンと文字は、余白やベースラインではなく `grid` / `flex` の中央揃えで配置する。
- ページの主役は一つ。フリーボードの入口には作業カードを重ねない。
- 角丸、紙色、ドット背景、線幅は他ページと同じデザインシステムを使う。
- プレビューは閲覧専用、編集は全画面キャンバスに分ける。
- 追加・移動・削除などの操作は、成功時の通知を設定で切替可能にする（注意・入力不足の通知は常に残す）。

## 確認手順

1. ローカルの実表示ページで、PCとスマホ幅の両方を確認する。
2. 既存メモ・目標・画像が表示されることを確認する。
3. テキスト、図形、メモ、手書き、画像の各ツールを一回ずつ試す。
4. 移動・削除・再表示後の保持を確認する。
5. 実装前後の確認は、コード表示や縮小スクリーンショットではなく、ブラウザで実画面を開いて行う。
