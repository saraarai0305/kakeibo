# 2026-08-09 共通紙面ルール

この文書は、承認済みの「支出・収入を記録」画面を全画面へ広げる際の追加規則です。以後、画面固有の調整より先にこの規則へ合わせます。

## 背景

- 背景は `#F6EFE1` のドット紙面のみ。通常背景に横罫線・グラデーション・別色の面を加えない。
- `html`、`body`、アプリ本体、各ページに同じ固定ドット背景を適用する。iPhoneで上下に引っ張った領域にも、紙面が切れずに続くこと。
- 横罫線や破線は、情報を区切るヘッダー・明細・入力欄の境界にだけ使用する。背景装飾には使わない。

## 共通ヘッダー

- 戻る／中央のロゴと「くらしのしるし」／設定は、同一の縦軸上に置く。
- 左右の操作は 58px 角。アイコンと文字は操作枠の中央に配置する。
- ロゴ行の実線と、日付行の点線は共通の高さを使う。日付と「くらしのしるし」は点線の上下中央に置く。
- ホームだけはハブ画面とし、見出しの `HOME` と `暮らしのアーカイブ` を表示しない。ロゴ・日付・三つの入口だけを残す。

## 見出し・アイコン

- セクションラベルは 26px アイコン、アイコンと英字ラベルの間隔は 5px。全画面で同じ値を使う。
- 英字ラベルから日本語の主見出しまでの距離は 6px。画面ごとに余白を増減させない。
- 表示文字は縦横比を変えない（`scaleX` / `scaleY` を使わない）。日本語・英字・数字とも 1:1 を原則とする。
- セクションラベル、入力ラベル、補助情報は同じ小見出しスケールを使う。数値は `tabular-nums` を使い、並びを安定させる。

## 明細

- 最近の支出は、上罫線から十分な余白をとり、カテゴリー名と金額を同じ行の左右端に揃える。
- カテゴリー色は小さな角丸四角で示し、分析の凡例と同じ色を使う。

## 確認手順

- 実装前後とも、コード文字列ではなく実表示できるローカル確認ページで確認する。
- ページ上端と下端をiPhone実機で引っ張り、背景が途切れないことを確認する。
- 新しいページを追加する場合は、この文書の背景・共通ヘッダー・見出し規則へ先に合わせてから固有の内容を組み込む。

## 7. 2026-08-09 追記：ヘッダーと五段階評価

- 共通ヘッダーは操作列を **72px**、日付列を **30px** に固定する。実線の下から点線までの余白は **7px** とし、日付とアプリ名は日付列の垂直中心に置く。
- 三本バーのロゴは見た目の重心を **1px下**、隣の「くらしのしるし」は **1px上**に補正し、二つを一組として同じ中心線に揃える。
- 「からだ」「こころ」の五段階評価は必ず **5個を横一列**に置く。各ボタンは **21pxの円形スタンプ**、選択済みは塗りつぶし＋紙色の内側リングで表現する。狭い画面でも折り返さない。

## 8. 2026-08-09 追記：配置保証（必ず先に読む）

### 目的

- 「少し右」「少し下」といった個別の目視指示がなくても、枠・文字・アイコンが自然に揃う実装にする。
- 文字のフォント固有のベースラインや見た目の上下余白を、レイアウトの基準に使わない。

### 実装上の原則

- 枠内の内容は `grid` または `flex` の **実際の中心揃え** (`place-items:center` / `align-items:center` / `justify-content:center`) で置く。`top`、負のマージン、変形で文字だけを追い込む実装は禁止する。
- アイコン＋文字の横並びは、アイコンを固定幅・固定高さの要素に入れ、親を `align-items:center` にする。文字のベースラインではなく、アイコンの描画領域と行ボックスの中央を揃える。
- 戻る、設定、ホームへ戻る、保存、追加、切替ボタンは **操作コンポーネント** として同じ中心規則を使う。ページごとに別の揃え方を作らない。
- 日付、ロゴ、アプリ名は **ヘッダー情報コンポーネント** として一つの行高・中央線を共有する。ロゴと文字の光学補正はこのコンポーネントだけに閉じ込め、他の画面へ個別コピーしない。
- 文字・数字・記号は縦横比 1:1 を維持する。`scaleX` / `scaleY` は使用しない。金額も同一の数値フォント、同一の太さ、`tabular-nums` を使う。

### 実装前・確認前のチェック

1. 枠内のアイコンと文字が、それぞれ X/Y 軸の中心へ揃うコンポーネントを使っているか。
2. 仕事／生活など二分割のレーンは、同じ親の `grid-template-columns: 1fr 1fr` と `left/right:50%` を共用しているか。余白で片側を狭くしない。
3. iPhone幅で、ページ上端・下端を引っ張ったときも `html`、`body`、アプリ本体の同一ドット紙面が続くか。
4. 確認は必ずコード文字列でなく、ローカル確認ページまたは iPhone幅の実表示で行う。

## 9. 2026-08-09 追記：仕事／生活・カレンダー・ホーム

- 時間割は中央の点線を基準に、左を **仕事**、右を **生活** とする。両レーンは同じ幅で、予定カードの余白も片側だけに加えない。
- 仕事アイコンは 2D のブリーフケース、生活アイコンは 2D の家を使う。どちらも 24px 方眼内、同じ線幅・角丸で描く。
- 週・月の予定は `すべて / 仕事 / 生活` で絞り込める。週間表示では、色線と予定名をセットで凡例に出し、色だけに意味を委ねない。
- ホームは三つの主入口を最優先にし、その下に日時・バージョンと、ユーザーが選べる三つの正方形ショートカットを置く。装飾は役割を邪魔しない範囲で紙面・印刷物らしさを補助する。
