# アイコン一覧：自由ボード追記

| 用途 | 表示 | 規則 |
| --- | --- | --- |
| テキスト | あ | 線画と並ぶため font-weight 400。太字の文字記号は使わない。 |
| 図形 | 既存の図形アイコン | 図形の追加ツール。 |
| メモ | 既存のメモアイコン | 付箋・メモの追加ツール。 |
| 手書き | 既存のペンアイコン | ドラッグで線を描くツール。 |
| 画像 | 既存の画像アイコン | 画像の追加ツール。 |
| 全画面表示 | `pay`（四隅フレーム） | QRコード風の四隅を示す既存アイコンを使用。 |
| 削除 | 既存の close アイコン | オールクリアを含む破壊操作は、確認を必須にする。 |
