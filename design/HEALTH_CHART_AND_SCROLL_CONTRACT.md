# 体調グラフと画面位置保持の契約

更新日: 2026-08-11

## 目的

利用者が選択・保存・削除をしたときに、見ていた場所を失わない。体調グラフは、普段は一覧として安定し、必要なときだけ拡大して細部を確認できるようにする。

## 原因（実測）

全画面を描き直す `newAppRender()` のラッパーが、すべての呼び出し後に `window.scrollTo(0, 0)` を実行していた。そのため、保存・選択・削除・切替のような画面遷移ではない操作でも、ページ先頭へ戻っていた。

## 共通ルール

| 操作 | 画面位置 |
| --- | --- |
| 保存、選択、削除、表示切替、入力項目の追加 | 現在の X/Y スクロール位置を保持する |
| 戻る、別ページへ進む、ホームへ戻る | 先頭から表示する |
| フリーボード内部の編集 | ページ位置とボード内の表示位置を両方保持する |

実装では `newAppRender()` は既定で描画前の位置を記録・復元し、ページ遷移だけ `preserveScroll: false` を渡す。画面ごとに `scrollTo(0,0)` を追加して直すことは禁止する。

## 体調グラフの操作契約

- 初期表示は倍率 1.0、位置 `(0, 0)`。ドラッグしても動かない。
- 二本指ピンチ（PC はホイール操作）で倍率を 1.0〜2.6 の範囲で変える。
- 倍率が 1.0 より大きいときだけ、一指／マウスドラッグでグラフを移動できる。
- 移動量は拡大後の表示範囲内に制限する。余白だけが見える位置まで移動させない。
- 倍率を 1.0 に戻したら位置も必ず `(0, 0)` に戻す。
- 拡大・移動直後のタップは詳細選択として扱わない。通常タップだけで数値詳細を出す。

## 合格条件

- [x] 保存・選択・削除でページが先頭へ戻らない。
- [x] 戻る／遷移／ホームへ戻るでは先頭から表示される。
- [x] 倍率 1.0 ではグラフがドラッグ移動しない。
- [x] 拡大後だけグラフをドラッグ移動できる。
- [x] 最大・最小倍率と移動範囲が制限されている。
- [ ] `http://127.0.0.1:8766/` の実表示で、スマホ幅・PC幅それぞれを確認する。

## 再発防止

操作を追加する前に、上の「操作 / 画面位置」表に分類を追加する。描画関数を変更した場合は、保存・削除・選択・戻るの4操作を実表示で確認してから公開する。
