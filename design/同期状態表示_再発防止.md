# 同期状態表示の再発防止

## 表示の意味

- `未接続`：GitHub トークンまたは Gist ID が未設定。
- `同期設定済み（通信未確認）`：端末に設定値は保存されているが、Gist 通信の成功は未確認。
- `接続確認済み`：実際の Gist 通信が成功し、最終同期時刻を保存できた状態。
- `接続エラー（確認が必要）`：直近の同期通信に失敗した状態。

## 禁止事項

- トークンと Gist ID の有無だけで「同期済み」「接続済み」と表示しない。
- 設定保存と、リモート通信成功を同じ状態として扱わない。

## 確認手順

1. 設定画面の「今すぐ同期する」を実行する。
2. 成功後にのみ `接続確認済み` が表示されることを確認する。
3. 失敗時はエラー表示を残し、Gist ID・トークン・ネットワークを確認する。
