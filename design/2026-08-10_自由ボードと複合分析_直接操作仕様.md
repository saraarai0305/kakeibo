# 自由ボードと複合分析 — 直接操作仕様

## この変更の目的

「くらしのしるし」は、家計・予定・習慣・こころとからだ・自己分析を一つの生活基盤として支える。忙しい日でも記録を続けられること、必要なときだけ深く分析できることを最優先にする。

今回の自由ボードは、入力欄の一覧ではなく、固定された表示枠の中でキャンバスを直接動かして考えを整理する場所とする。体調分析は、別々のグラフを読むのではなく、同じ曜日軸で睡眠・歩数・からだ・こころ・毎日の習慣を比較する。

## 自由ボードの直接操作契約

- 表示枠は固定し、空白をドラッグすると**ボード内部だけ**を移動する。ページ全体は動かさない。
- 二本指のピンチでボードを拡大・縮小する。
- ツールは「選択 / テキスト / 図形 / メモ / 手書き / 画像」。ツールを選んだあと、ボードをタップして追加する。
- テキストは 1 回タップでオブジェクト選択、2 回タップで編集ポップアップを開く。保存時に文字量から枠の幅・高さを自動調整し、内容を切り捨てない。
- 図形・メモ・画像・手書きは、長押し後のドラッグで移動する。選択中の角/辺ハンドルで大きさを変更できる。
- テキストを含むボックスは、内容が読み切れることを優先し、手動リサイズしない。
- 選択中だけ流れる点線（marching ants）を表示する。強い横揺れアニメーションは使わない。
- 選択中のオブジェクト右上の × は即時削除。選択対象以外の空白タップで選択解除。
- 書体・太さ・文字サイズは編集ポップアップで設定する。文字サイズは数値入力にする。

## 体調の複合グラフ

- 横軸は曜日を共通化する。
- 睡眠（青）と歩数（緑）は同じ曜日位置に重ねた棒グラフで表示する。
- からだ（紫・丸）、こころ（コーラル・四角の点線）、毎日の習慣（黄・三角の点線）は折れ線で表示する。
- 各データの値域は個別に正規化する。睡眠は 3–10 時間、歩数は 0–12,000 歩、からだ/こころは 1–5、習慣は 0–100 % を基準にする。
- 点または折れ線をタップして値を表示する。棒が重なる場所は、同じ場所を連続タップすると睡眠→歩数の順で切り替える。
- グラフ全体は二本指で拡大できる。詳細表示にはアニメーションを付けない。
- 振り返りは平均睡眠・平均歩数・概算消費カロリー・同じ週の相関（十分な記録があるときのみ）を表示する。

## AI 分析の扱い

- PWA の JavaScript 内に API キーを置かない。ブラウザに埋め込んだキーは閲覧者に取得されるため禁止。
- まず端末内のデータだけで説明可能な傾向を表示する。
- AI 分析を提供するときは、将来サーバー側に認証済みの中継 API を作り、最小限に匿名化した集計値だけを送る。分析文には「診断ではない」ことと使用データ範囲を表示する。
- 医療上の緊急性・診断・治療の判断は行わない。

## 実装・確認の原則（再発防止）

- 枠内の文字・記号・アイコンは `grid` / `flex` の中央揃えを基本にし、フォントのベースラインや余白だけに依存しない。
- 選択・削除・ドラッグ・ピンチなどの状態は、静止時と明確に区別できる表示にする。
- 変更後は**実表示できるローカル確認ページ**をブラウザで開き、操作まで確認する。コードの生表示や低解像度のスクリーンショットだけを確認手段にしない。
- 修正依頼は実装前にこの設計記録へ追記し、原因・再発防止・該当画面を残す。
