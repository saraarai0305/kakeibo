# LIFE NOTE 運用デザイン規則

最終更新: 2026-08-08
適用対象: `ui-v2.js`、`ui-analog.css`、紙面モックアップ

この資料は、画面やアイコンを変更する前に必ず確認する「現在の正」とする。変更を行ったときは、実装と同じコミットで末尾の変更履歴へ追記する。

## 1. 画面の骨格

- 対象は iPhone 縦向き。横向き専用のレイアウトは作らない。
- ホーム・記録する・今日を整える・見える化するは、1画面に収まる入口画面としてスクロールをロックする。
- 下に情報が続く画面だけ、自然な縦スクロールを許可する。無意味な余白や、画面内で完結する内容のためのスクロールは禁止。
- ヘッダーは `48px / 可変 / 48px` の3列。戻ると設定の枠は44px角、両方の中心を画面の中心線に対して対称に置く。
- 「戻る」は一つ前の画面へ戻る。「ホームへ戻る」は各詳細画面の下端に置き、入口へ直接戻る。

## 2. 文字と日付

- 本文・入力・ボタン・画面タイトル・主要金額: `Hiragino Sans / Yu Gothic / system-ui`。機能画面では可読性と操作の一貫性を優先する。
- 明朝系は「くらしのしるし」の装飾的ロゴ、またはフリーボードで利用者が明示して選ぶ本文表現だけに限る。機能画面の見出し・設定・操作・金額には使わない。
- 数字は `tabular-nums` を使い、金額や時刻の桁を揃える。
- 固定文言の `AUGUST` や `ISSUE 08/2026` は使わない。ヘッダーとホームの小さな日付表示は、端末の当日の日付を `YYYY.MM.DD` で出す。

## 3. アイコン

- 線画は2Dのみ。線端は丸、線幅は原則1.85px。
- 通常アイコンは24px。54pxの座布団内では30px、ホームの主導線では31px。座布団の大きさは変えない。
- 設定は横線3本のメニューアイコン。
- お金は円の中の余白を確保した短い上部の `¥`。支出と収入は下向き／上向き矢印で区別する。
- 設定の5項目は、承認済みの2Dフォルダアイコンを使う。
- 新しいアイコンを追加・変更したら、アイコン一覧とこの変更履歴に理由を記す。

## 4. 色・面・余白

- 背景は紙色 `#F6EFE1`、文字は墨色 `#21312D`、罫線は `#C6B9A2`。
- 色の役割: お金/支出は青 `#527CA4`、収入/肯定は緑 `#4F986F`、こころ/注意はコーラル `#CA796B`、こよみ/分析は紫 `#796AA8`、生活/期限は黄 `#D2A449`。
- 重要面は1画面に1つまで。通常の区切りはカードを増やさず、余白・罫線・左側の色帯で作る。
- 主ボタンは最低54px、補助操作は44px以上。いずれも視覚的・操作的な中心を揃える。

## 5. アニメーション

- 画面遷移: 190ms、右から入る。戻るは履歴の方向を崩さない。
- 押下: 最大2px移動と影の短縮のみ。
- 保存完了: 必要なときだけ短いスタンプ演出を使う。
- 常時動く装飾は禁止。テーマの横送りだけは、文字が収まらない場合に限る。
- `prefers-reduced-motion` ではすべて即時表示にする。

### 2026-08-08 — 上部構成・文字組み・操作部品の再固定

- **画面の上部は二層構成に固定する。** 第1層は「戻る／画面名／設定」の操作列、第2層は「用途アイコン＋英字ラベル＋日本語タイトル」の情報見出し。ページ固有のタイトルをこの二層以外に重ねない。
- ホームの情報見出しは `ホームアイコン / HOME / 暮らしのアーカイブ` とし、右下の小さな印字に当日の日付と `LIFE NOTE` を置く。
- **ナビゲーション操作は同じ部類の部品として扱う。** 戻る、設定、ホームへ戻るはすべて「画面移動操作」。戻る／設定は56px角、アイコン24px＋ラベル10pxを縦に中央揃えする。ホームへ戻るは画面最下部の同じ紙面色の操作帯に置く。
- 戻ると設定の左右列は常に64pxで同幅にする。要素の有無にかかわらず空の56pxスペーサーを残し、中央タイトルの光学中心を動かさない。
- 日本語の主見出し・英字ラベル・本文・操作ラベルは `Hiragino Sans / Yu Gothic`。日本語と数字が混ざる要素では `kern` を有効、`palt` を無効、`lining-nums + tabular-nums` を有効にして、数字の基線・幅・字間を固定する。明朝系を使う場合は装飾用途である理由を仕様に明記する。
- 睡眠編集は睡眠カードの内部に置く。独立した横長操作を後ろに追加しない。
- 分析の入口アイコンは意味で区別する。お金の分析はお金アイコン、体調の分析はからだアイコンを使う。汎用の分析アイコンを連続使用しない。
- ページの最小高を `100dvh`、アプリの土台を同じ紙面背景に固定する。コンテンツが短い場合も、引っ張った先で背景・罫線が急に切り替わらないようにする。

### 2026-08-08 — 上部余白とマストヘッドのリズムを再固定

- **画面の最初に空白の演出を置かない。** iPhone の安全領域の直後から、戻る／画面名／設定の操作列を始める。ページ親要素は上寄せの通常フローとし、中央寄せ・疑似スペーサー・先頭の大きな余白を追加しない。
- マストヘッドは `英字ラベル → 日本語タイトル → 本文` の三段だけにする。英字ラベルと日本語タイトルの間隔は 6px、日本語タイトル後は 18px。画面ごとに別の余白を足さない。
- 日本語タイトルは 28–35px、行高 1.12、字間 0.006em。見出しを大きくして迫力を出すのではなく、英字ラベル・アイコン・余白との比率で優先度を示す。英字ラベルは 15px の太字ゴシックを維持する。
- マストヘッドのアイコン座は 44×36px、アイコンは 34px。ラベルの文字中心とアイコンの光学中心を揃え、タイトルの左端とも揃える。
- レイアウトを更新する際は、必ず「安全領域 → 操作列 → 日付/LIFE NOTE → マストヘッド」の順に上から確認する。画面上部にまとまった無目的な紙面余白が発生していないことを、公開前の確認項目に加える。

### 2026-08-08 — 文字の密度と比較グラフの規則

- 日本語のマストヘッドは 24–30px を上限にする。英字ラベル（15px）との比率で用途を示し、巨大なタイトルで紙面を占有しない。
- グラフ見出しは16px、切替ラベルは11px。切替は角丸のピル形状に統一し、角張った四角を局所的に増やさない。
- 体調分析は「日付」を横軸で共通化し、指標の縦軸は混在させない。睡眠は3–10時間、歩数は0–12,000歩、からだ・こころは1–5を個別レンジとして表示する。睡眠・歩数は棒、からだ・こころは線で表現し、同じ日に何が起きたかを比較可能にする。
- ホームへ戻るも画面移動操作の一種として、戻る・設定と同じ紙面、罫線、角丸、影の規則を使う。長いラベルは横並びで収め、操作領域は56px以上を保つ。
- 画面遷移・再描画時は必ずページ先頭へ即時復帰する。スクロール位置の復元で上部操作列が画面外に残る状態を許容しない。
